## 1. 과목, 교수님, 학생

- 2026-2학기 IoT 스마트홈 (교과목 번호 07586, 전공선택 3학점). 담당교수 김철재, 공정식.
- 김철재 교수님은 한국정보통신자격협회(ICQA) 전략기획팀장이고, 스마트홈관리사 자격 체계를 만들었으며, 국가공인 **지능형홈관리사** 출제, 감수, 채점 전문위원 네트워크에 있다(1강 p.2). 그래서 수업 시험이 지능형홈관리사 시험과 비슷할 가능성이 크다.
- 학생: 공간디자인 전공(예체능 출신이 많다)이 전자과 수준의 수업을 듣고 있어서 매우 힘들어한다. 전기, 신호, 통신, 네트워크 기초가 전혀 없다고 가정한다. 여러 번 회독하며 익숙해지고, 보기만 해도 용어가 외워지게, 클릭하면서 재미있게.

## 4. 시험 모양

- 수업 시험 형식은 아직 공지 없음. 교수님이 지능형홈관리사를 만든 사람이라 4지 택일 비중이 클 것으로 본다. 그래도 기출이 시험마다 달라서 **객관식, O/X, 단답, 서술을 고르게** 연습시킨다.
- 지능형홈관리사 필기: 4지 택일 40문항 40분. 영역은 지능형홈 개론, 네트워크, 기기(`exam_analysis.md`). "가장 적절한 것은?", "옳지 않은 것은?", 지문 상자를 주고 해당 사례를 고르는 모양이 많다.
- 기출에서 자주 나온 주제: 네트워크 보안(3대 원칙, 암호화, 방화벽), 근거리 무선(Wi-Fi, NFC, RFID, Thread, RS-485), 센서 종류와 선택, 스마트 플러그와 스위치와 허브의 할 수 있는 일, AI 학습 방식, 전기 기초(P=V×I, 누전차단기, PoE), 포그/엣지/클라우드, 기술기준(홈네트워크 설비, 홈게이트웨이), 무선 범위 순서(WPAN < WLAN < WMAN < WWAN)와 2.4GHz 간섭.
- 실기: 슬라이드에 "실기 시뮬레이터 [과업 3-1 통신 프로토콜 이해], [과업 3-4 허브 연결 설정]" 처럼 연계 표기가 있다.

## 5. 회독 단계

용어가 매우 많고 학생들이 전자, 통신을 처음 접해서, 쉬운 층을 하나 더 두어 **5회독**으로 만든다. 그리고 사이트가 0회독 "용어 먼저"(쪽마다 `terms` 카드)를 자동으로 붙인다. 층 내용은 `회독레슨_작성규칙.md` 3절의 층 사전.

| 회독 | JSON 키 | 층 이름 | 이 과목에서 |
|---|---|---|---|
| 0 | (자동) | 용어 먼저 | 쪽마다 `terms` 카드. 그래서 `terms` 를 빠짐없이 |
| 1 | pass1 | 큰 그림 | 초등학생도 알아듣게. 비유는 6절 것만 |
| 2 | pass2 | 흐름과 뜻 | 이 쪽 용어 하나하나의 뜻, 비슷한 용어 구별(허브와 게이트웨이, Zigbee 와 Z-Wave), 감지 → 전달 → 판단 → 실행 흐름 |
| 3 | pass3 | 자세히 | 슬라이드의 표, 주파수, 거리, 규격, 표준 이름 빠짐없이 |
| 4 | pass4 | 기출 | 지능형홈관리사 기출(`wx_exam.json` 의 번호와 풀이), 확인 퀴즈, 답안 문장, 주의 |
| 5 | pass5 | 실기 연결 | 슬라이드에 적힌 실기 과업 번호, 실기 가이드북 2권의 해당 과업(준비물, 순서, 확인 항목, 흔한 실수)을 슬라이드 개념과 짝지어. 가이드북에 없는 절차는 쓰지 않는다. 관련 없는 쪽은 빈 배열 |

## 6. 주문과 비유 (과목 전체에서 이것만)

- 주문: **"센서가 느끼고, 네트워크가 나르고, 허브와 플랫폼이 판단하고, 기기가 움직여요."** (감지, 전달, 판단, 실행)
- 비유: 센서 = 눈, 코, 피부 같은 감각기관 / 액추에이터 = 손발 / 허브 = 반 반장 / 프로토콜 = 서로 쓰는 언어 / 게이트웨이 = 통역사 / 주파수 대역 = 라디오 채널 / 메시 네트워크 = 친구끼리 쪽지 릴레이 / 엣지 = 우리 집 책상에서 바로 처리 / 클라우드 = 먼 곳의 큰 도서관.

## 7. 기초 다지기 단원 후보 (week "b", wb-1 ~ wb-10)

1. 전기 처음부터: 전압, 전류, 저항, 전력(P = V × I), 직류와 교류, 누전차단기, PoE
2. 신호와 숫자: 아날로그와 디지털, 비트와 바이트, 단위(k, M, G), 0과 1로 켜고 끄기
3. 센서와 액추에이터: 감지하는 방법(PIR, 온습도, 미세먼지, 자이로, 문열림), 입력과 출력
4. 파동과 전파: 주파수, 파장, Hz, dB, 감쇠, 벽 투과
5. 무선의 저울: 거리, 속도, 전력, 대역폭의 맞바꿈, WPAN, WLAN, WMAN, WWAN, LPWAN
6. 네트워크 모양: 노드, 스타, 메시, 트리, 허브, 스위치, 라우터, AP, 게이트웨이
7. 주소와 약속: IP 주소, MAC 주소, 프로토콜, 계층, 표준(IEEE 802.11, 802.15.4)
8. 인터넷과 클라우드: 서버, 클라우드, 엣지, 포그, 앱과 플랫폼
9. 데이터와 AI: 데이터 유형(상태, 이벤트, 시계열), 규칙 기반과 학습, 지도, 비지도, 강화 학습
10. 보안과 개인정보: 기밀성, 무결성, 가용성, 암호화, 인증, 개인정보 보호법의 기본 개념

사실은 필기 가이드북, 용어해설집, 일반 기초 상식에서. 단원 끝 "이게 이 과목 어디에 나오나" 에 강의 주차와 기출 번호를 적는다.
