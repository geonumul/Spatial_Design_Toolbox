암기 팁

정확한 문장은 정리노트 원문에 있어요. 여기는 헷갈리는 짝, 숫자, 순서를 머리에 넣는 용도예요.

1. 큰 그림: 공사 한 건의 일생

① 누가발주자(갑) → 설계자 → 감리자 → 시공자(원도급, 하도급) → 노무자(직용, 정용, 임시)
② 어떻게 맡기나직영 / 도급(시행방식 : 일식, 분할, 공동 / 지급방식 : 정액, 단가, 실비정산보수가산) / 턴키
③ 누구에게공개경쟁 → 제한경쟁 → 지명경쟁 → 수의계약 (문이 점점 좁아짐)
④ 계획현장 조사 → 법규 검토 → 실행내역서 → 공정계획
⑤ 관리착공 준비 → 착공 → 현장, 안전, 품질, 자재관리
⑥ 마무리준공청소 → 준공정산 → 준공검사 → 유지관리 계획

암기 문장: 사람 → 방식 → 입찰 → 계획 → 관리 → 준공. 현장 작업은 가설 → 철거 → 경량철골 → 마감.

4. 공사원가 양파 까기

  1. 직접공사비 = 재료비 + 노무비 + 외주비 + 경비
  2. 순공사비 = 직접공사비 + (공통 가설비, 간접공사비)
  3. 공사원가 = 순공사비 + 현장경비
  4. 총원가 = 공사원가 + 일반관리비
  5. 공사비(계약금액) = 총원가 + 부가이윤 및 부가가치세

"재노외경 → 간접 → 현장 → 일반 → 이윤". 안에서 밖으로, 현장에서 본사로 멀어져요. 실행내역 = 계약금액에서 일반관리비와 이윤을 뺀 공사원가(대외비).

5. 순서 외우기

입찰 : 공고 → 참가신청 → 보증금 → PQ → 현장설명 → 투찰 → 개찰, 낙찰 → 계약

"공신보P현투낙계" (공고, 신청, 보증금, PQ, 현장설명, 투찰, 낙찰, 계약)

실측 : 전체 스케치 → 평면도 → 입면도(방마다 4면) → 천장도. 3곳 재서 가장 작은(낮은) 치수

건식벽체 9단계 : 먹매김 → 하부 런너 → 시작 스터드 → 상부 런너 → 스터드 → 바탕 보드 → 단열재 → 반대쪽 바탕 1ply → 마감 2ply

"먹, 아래, 시작, 위, 기둥으로 뼈대 → 보드, 솜, 보드, 보드로 살". 한쪽을 막고 솜을 넣어야 반대쪽을 막을 수 있어요.

M-Bar 9단계 : 스트롱 앵커 → 테두리 몰딩 → 행거볼트, 행거 → 캐링 채널 → 마이너 채널 → M-Bar → 수평 → 1ply → 2ply

T-Bar 7단계 : 앵커 → 몰딩 → 행거(여기까지 M-Bar와 같음) → 캐링 채널 + 메인 T-Bar(C/T 클립) → 크로스 T-Bar → 수평 → 텍스

천장은 "위에서 아래로 매달기": 슬라브에 박고(앵커) → 내리고(볼트) → 굵은 뼈(캐링) → 묶고(마이너) → 가는 뼈(M, T) → 판. 텍스는 전기, 설비 끝난 뒤.

준공 : 준공청소 → 준공정산(준공내역서, 준공도면) → 준공검사 → 유지관리 계획

6. 목록형 서술 뼈대

  • 공사관계자 5 발주자, 설계자, 감리자, 시공자, 노무자
  • 시공관리 목적 4 신속(공정), 우수(품질), 안전(안전), 경제(원가)
  • 현장관리 5 공정, 품질, 안전, 원가, 현장운영관리
  • 공정계획 요소 4 시기, 내용, 수량, 인력 / 수단 4 : 인력, 장비, 자금, 자원
  • 안전점검 3 일상점검, 정기점검, 수시점검
  • 품질관리 목적 4 합리적, 경제적, 내구적, 심미적
  • 경량철골 장점 5 불연, 자중 감소, 공기 단축, 내화와 차음 성능 구현, 설비 설치 간단
  • 비계 4 + 1 강관, 시스템, 조립식(이동틀), 말비계 + 시저 리프트
  • 보양재 6 합판, 비닐, 골판지, 각대, 고무판, 에어매트
  • 현장사무실 3 임시 칸막이, 컨테이너 하우스, 샌드위치 패널
  • 철거공법 4 기계력, 유압력, 폭발력(거의 안 씀), 인력(실내 보편)
  • 안전장구 머리부터 안전모, 보호면, 방진 마스크, 안전 조끼, 안전대, 각반, 안전화

7. 시험에서 잘 걸리는 함정

  • 가설공사는 설계도에 일반적으로 표시되지 않고 현장소장 책임. "설계자 책임"이 아님
  • 먹매김 참여자는 설계자, 현장소장, 목수. 먹도면은 설계자가 준비
  • 인테리어는 의무 감리제도가 없음. 그래도 품질관리를 위해 시행
  • '갑', '을' 표기와 간인은 법적 의무가 아님
  • 착공 준비에서 가장 먼저 정하는 것은 현장 담당자 구성
  • 시멘트는 통풍 좋은 곳이 아니라 외기 유입이 안 되는 곳에 보관
  • 용접은 페인트 도장, 우레탄 발포와 병행 금지
  • 석면 함유 슬레이트와 텍스는 건설폐기물에서 제외
  • 방음벽은 텍스 천장이 아니라 보, 슬라브까지
  • 천장 보드 고정은 나사못. 원문 한 곳에 "타카핀이나 나사못"이 있지만 시공 그림은 "타카 사용 절대 금지"
  • 캐링 채널 방향을 벽체 스터드 방향과 헷갈리지 않게
