기출 분석

이전 시험 답안으로 본 시험 모양

같은 교수님의 이전 과목(친환경주거) 시험 답안 공지 한 장을 보고, 문제가 어떤 모양이었는지 거꾸로 짚었어요. 문제 원문은 없어서 추정이에요.

1. 15문항, 네 가지 모양

번호모양답안에 나온 내용
1~6선택형 (옳지 않은 것 고르기로 보임, 보기 5개)수평 온도차가 수직 온도차보다 쾌적성에 더 큰 영향 / 증산지배형 방산 화학물질은 단기간 제거가 어렵다 / 휘도는 보는 거리에 따라 변한다 / 소음환경기준 '나' 지역에 일반주거지역이 포함되지 않는다 / 채광 1/7 이상 / 총휘발성유기화합물(TVOC)
7순서 나열단열 좋음 열용량 큼 → 단열 나쁨 열용량 큼 → 단열 좋음 열용량 작음 → 단열 나쁨 열용량 작음
8, 9단답 (용어)열교 / 확산
10나열형 (각 0.5점)단열재 종류: 저항형, 반사형, 용량형
11나열형 (기법 이름, 각 0.5점)차양장치: 브리즈솔레이유, 루버, 블라인드, 어닝 중 1개 / 자연환기: 환기굴뚝, 에코샤프트, 윈드카울 중 1개 / 단열: 외단열, 복합외단열시스템(EIFS)도 인정
12단답 (각 1점)phon, dB(A), 기준음압
13나열형 (각 1점)실내공기질 관리 대상: 다중이용시설, 신축공동주택, 대중교통차량
14나열형 (각 1점)열쾌적 요소: 기온, 상대습도, 주위벽면온도(평균복사온도 MRT), 기류속도, 착의량(의복량), 활동량(대사량)
15계산 (식 1.5점, 답 1.5점)환기횟수 = (필요환기량 x 재실자수) / 실의용적 = (24 x 5) / 60 = 2회

객관식만 연습하면 안 돼요. 용어 단답, 여러 개를 쓰는 나열형(부분 점수), 식과 답을 함께 쓰는 계산이 절반이 넘어요.

2. 어디서 공부하나

  • 열, 단열, 열교, 결로, 습기 기초 다지기 1~5단원
  • 열쾌적 6요소 기초 다지기 6단원
  • 환기, 환기횟수 계산 기초 다지기 7단원
  • 실내공기질, TVOC 기초 다지기 8단원
  • 빛, 휘도, 채광, 차양장치 기초 다지기 9단원
  • 소리, phon, dB(A) 기초 다지기 10단원

이 주제들은 1주차(친환경건축의 개념) 강의에는 아직 안 나왔어요. 해당 주차 강의가 올라오면 3회독 기출에 연결해요. 문제풀기에서 "기출만" 을 누르면 답안을 바탕으로 다시 만든 15문항을 풀 수 있어요.
