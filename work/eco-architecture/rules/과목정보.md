## 4. 시험 모양 (답안 캡처에서 거꾸로 추정)

15문항 구성으로 보인다.
- 1~6번 선택형: 답이 "(2) 수평의 온도차가 수직의 온도차보다 쾌적성에 더 큰 영향을 미친다" 처럼 문장 번호라서 "옳지 않은 것" 을 고르는 5지선다로 보인다((5) 번이 있음).
- 7~9번 단답: 순서 나열(단열 좋음/나쁨 × 열용량 큼/작음), 용어(열교), 용어(확산).
- 10~11번 나열형 부분점수(각 0.5점): 단열재 종류(저항형, 반사형, 용량형), 기법 이름(차양장치: 브리즈솔레이유, 루버, 블라인드, 어닝 중 1개 / 자연환기: 환기굴뚝, 에코샤프트, 윈드카울 중 1개 / 단열: 외단열, 복합외단열시스템(EIFS) 인정).
- 12~14번 각 1점: 소리 단위(phon, dB(A), 기준음압), 실내공기질 관리 대상(다중이용시설, 신축공동주택, 대중교통차량), 열쾌적 요소(기온, 상대습도, 주위벽면온도(평균복사온도, MRT), 기류속도, 착의량, 활동량(대사량)).
- 15번 계산 3점(식 1.5점, 답 1.5점): 환기횟수 = (필요환기량 × 재실자수) / 실의용적 = (24 × 5) / 60 = 2회.
- 그 밖에 답에 나온 사실: 증산지배형으로 방산되는 화학물질은 단기간 제거가 어렵다, 휘도 값은 보는 거리에 따라 변한다(가 옳지 않은 문장), 소음환경기준 '나' 지역에는 일반주거지역이 포함되지 않는다(가 옳지 않은 문장), 채광 1/7 이상, 총휘발성유기화합물(TVOC).

→ 이 주제들은 1주차 개념 강의에는 아직 나오지 않았다. **기초 다지기에서 0부터** 다루고, 해당 주차 강의가 들어오면 3회독 기출로 연결한다. 문제은행은 선택형, 단답, 나열형(essay), 계산(calc)을 이 모양대로 섞는다. 답안 캡처의 문항은 원문 문제가 없으므로 "기출 답안 기반 재구성" 이라고 `src` 에 적고, 답에 드러난 사실만으로 문제를 만든다.

1회독 큰 그림, 2회독 자세히, 3회독 기출. (실습, 실기 짝이 없어서 4회독은 없다. pass4 는 빈 배열)

## 6. 주문과 비유 (과목 전체에서 이것만)

- 주문: **"자연에서 빌려 쓰고, 돌려주며 순환시켜요."** (에너지, 재료, 녹지, 물, 공기 다섯 가지 순환)
- 비유: 건물 = 사람 몸(외피 = 피부, 환기 = 숨쉬기, 증발냉각 = 땀) / 단열 = 겨울 패딩 / 열용량 = 뚝배기(늦게 데워지고 늦게 식어요) / 열교 = 패딩의 지퍼 틈 / 결로 = 차가운 컵에 맺히는 물방울 / 자연환기 = 창문 열어 맞바람.

## 7. 기초 다지기 단원 후보 (week "b", wb-1 ~ wb-10)

1. 온도와 열: 열은 뜨거운 곳에서 차가운 곳으로, 전도, 대류, 복사
2. 단열: 열이 새는 길 막기, 열저항과 열관류율(U값, 숫자가 작을수록 단열이 좋음), 단열재 종류(저항형, 반사형, 용량형), 외단열과 EIFS
3. 열용량과 축열: 뚝배기와 양은냄비, "단열 좋음/나쁨 × 열용량 큼/작음" 네 경우의 실내 온도 변화 순서
4. 열교와 결로: 이슬점, 표면 결로, 내부 결로, 열교를 막는 외단열
5. 습기: 상대습도, 수증기의 확산, 방습층
6. 열쾌적: 여섯 요소(기온, 상대습도, 평균복사온도 MRT, 기류속도, 착의량, 활동량), 수직 온도차가 수평 온도차보다 불쾌감이 크다
7. 공기와 환기: 필요환기량, 환기횟수 손계산(답안 캡처 15번 모양), 자연환기 원리(굴뚝 효과, 맞통풍)와 기법(환기굴뚝, 에코샤프트, 윈드카울)
8. 실내공기질: VOC, TVOC, 폼알데하이드, 방산 방식(증발지배형, 증산지배형), 관리 대상 시설
9. 빛: 광속, 조도, 휘도(보는 방향에 따라 달라지고 거리와는 무관), 채광(창 면적 1/7 이상), 차양장치(브리즈솔레이유, 루버, 블라인드, 어닝)
10. 소리: dB, dB(A), phon, 기준음압, 소음환경기준 지역 구분

확실하지 않은 수치는 쓰지 않는다. 답안 캡처의 사실은 그대로 써도 된다. 계산은 Python 으로 assert.
