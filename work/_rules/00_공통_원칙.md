# 공통 원칙 (모든 과목, 모든 작성자)

이 폴더의 규칙은 "강의 하나를 수업 없이 혼자서도 완벽히 공부할 수 있게" 만드는 방식이다. 원본은 `인수인계\` 폴더(그래프 신경망 강의에서 사용자에게 검증받은 방식)이고, 공간디자인 수업 과목에 맞게 옮겼다. 과목별로 달라지는 것(자료 위치, 시험 모양, 교수님, 용어 사전)은 `work\<과목>\rules\과목정보.md` 에 있다. **작업 전에 이 파일, 맡은 일의 작성규칙, 과목정보를 모두 읽는다.**

## 1. 독자

- 공간디자인학과 학생들. 예체능 계열로 들어온 학생이 많고, 전자, 통신, 건축환경, 영양 같은 전공 밖 과목의 선수 지식이 **하나도 없다**고 가정한다.
- 긴 글, 불친절한 요약, 한 번에 쏟아지는 정보를 못 읽는다. "너무 불친절하다", "안 읽힌다" 는 말을 듣지 않게 쓴다.
- 원하는 것: **중학생도 이해할 만큼 떠먹여 주기, 반복해서 읽기만 해도 외워지기, 동영상 보듯 버튼 누르며 넘기기, 쉬운 것부터 여러 번 회독, 전문용어 자동 암기, 게임처럼 누르면서 재미있게.**
- 목표는 시험이다. 시험과 연결되지 않은 내용은 가치가 낮다. 다만 기출이 시험마다 달라서, 문제는 한 모양에 치우치지 않고 **다양한 유형(객관식, O/X, 단답, 서술, 계산)** 으로 낸다. 사용자가 준 기출은 그대로 반영한다.

## 2. 절대 규칙

1. **em dash, en dash, 가운뎃점 문자를 쓰지 않는다.** 문서, JSON, SVG 글자, 코드 주석 전부. 쉼표, 마침표, 하이픈(-), 슬래시, 괄호, 화살표(→)로 대체. 원본 슬라이드에 있어도 옮길 때 바꾼다. 검사기가 잡는다.
2. **원본 자료는 절대 수정하지 않는다.** 결과물은 맡은 출력 경로에만 쓴다.
3. **슬라이드와 제공 자료에 없는 사실을 지어내지 않는다.** 이해를 돕는 일반 상식(전압이 뭔지, 파장이 뭔지)은 괜찮다. 확실하지 않으면 쓰지 않는다. 슬라이드 오류는 고치지 말고 "헷갈리기 쉬운 점"으로 알려 준다.
4. 한국어 존댓말 "~요". 한 문단 2~4문장. 한 문장이 길면 끊는다.
5. 회독 레슨, 정리 슬라이드 JSON 에는 **이모지 금지**.
6. 계산 문제의 정답은 **Python 으로 실제 계산해서 assert** 로 확인한다.
7. 맡은 범위는 **끝까지 다 한다.** 일부만 하고 멈추지 않는다.

## 3. 떠먹여주기, 반복, 용어

- **비유 먼저, 정확한 용어는 반드시 그다음.** 비유만 하고 끝내지 않는다. 과목정보에 정한 비유를 과목 전체에서 계속 쓴다(새 비유를 매번 만들면 헷갈린다).
- 과목을 관통하는 **주문**(과목정보에 있음)을 계속 반복한다.
- "다시 말하면", "한 번 더", "즉" 을 아끼지 않는다. 앞 슬라이드 내용을 불러와서 이어 준다.
- 기본 정의(과목정보의 핵심 용어)는 나올 때마다 한 줄로 뜻을 다시 붙인다.
- **전문용어 표기**: 나올 때마다 **매번** `**한국어(English)**` 형식. 영어 이름이 없는 용어는 `**한국어**`, 영어가 곧 정식 이름인 용어는 `**Zigbee(지그비)**` 처럼 과목 용어 사전 표기를 그대로 쓴다. 시험에 정식 용어로 나오므로 용어 자체를 쉬운 말로 바꾸지 않는다. 쉬운 것은 설명뿐이다.
- 용어 데이터 형식: `{"ko": "허브", "en": "Hub", "say": "집 안 기기들을 한데 모아 주는 반장 같은 장치", "more": "여러 무선 기기의 신호를 받아 인터넷 쪽으로 이어 주고, 인터넷이 끊겨도 집 안 자동화를 돌려요."}`. `ko` 는 한국어 이름(없으면 빈 문자열), `en` 은 영어 이름(없으면 빈 문자열), `say` 는 아주 쉬운 한 문장, `more`(선택) 는 조금 더 들어간 한두 문장. 사이트가 용어를 누르면 say 다음에 more 를 보여 주고, 0회독과 용어 카드에서도 쓴다.
- 용어는 한 번 읽어서는 안 익숙해진다. 사이트가 0회독(용어 먼저), 용어 카드 간격 반복(알면 1, 2, 4, 7, 15일 뒤 다시), 단원 시작 복습 카드로 반복시키므로, 작성자는 **용어 표기를 사전과 똑같이, 쪽마다 terms 를 빠짐없이** 적는 데 신경 쓴다. **과목 용어 사전(`rules\용어사전.json`)에 있는 용어는 그 표기를 그대로 쓴다.** 한 글자짜리 용어는 만들지 않는다(사이트가 본문에서 용어를 자동으로 찾아 강조하는데 한 글자는 엉뚱한 곳에 걸린다).
- 한 파일(단원) 안에서 각 용어가 3번 이상 나오게 쓴다. 앞 단원 용어를 2개 이상 다시 부른다.

## 4. 파일, 경로, 검사

- 저장소: `D:\GRAPH_LECTURE_OJLEE\03_사이트\Toolbox_Group_Study`
- 과목 작업 폴더 `work\<과목>\`: `lecture\`(강의안 md), `lesson\`(회독 레슨 json), `notes\`(정리 슬라이드, 기초 다지기 json), `bank\`(문제 json), `pages\`(기출 분석, 답안 팁 html), `rules\`(과목정보, 용어 사전), `_src\`(추출 텍스트, 작성용 슬라이드 PNG `_src\png\<덱>\pNNN.png`).
- 사이트 슬라이드 그림: `subjects\<과목>\img\<덱>\pNNN.jpg`.
- JSON 은 반드시 **Python 생성 스크립트**로 만든다(`json.dump(..., ensure_ascii=False, indent=1)`). 수식이 있으면 raw string `r"..."`.
- 여러 작성자가 같은 폴더를 쓴다. **임시 파일은 맡은 범위를 붙인 고유 이름**(예 `I3_001-016_tmp.py`). `tmp.py`, `part1.md` 같은 흔한 이름 금지.
- 검사기(통과할 때까지 고친다):
  - 강의안 `python tools\checkers\lecture_check.py <md> <시작쪽> <끝쪽>`
  - 회독 레슨 `python tools\checkers\lesson_check.py <json> <시작쪽> <끝쪽>`
  - 정리 슬라이드, 기초 다지기 `python tools\checkers\slide_check.py <json>`
  - 문제은행 `python tools\checkers\bank_check.py <json>`
- 최종 답은 짧게: 검사기 결과 + 확실하지 않았던 점(슬라이드 오류, 추정한 값) 3줄. 만든 내용을 답에 붙여 넣지 않는다.
