# 회독 레슨 작성 규칙 (강의를 "동영상 같은 슬라이드" 로, 여러 번 회독)

먼저 `00_공통_원칙.md`, `work\<과목>\rules\과목정보.md`, 그리고 `정리슬라이드_작성규칙.md` 3, 4절(장면 종류, SVG 규칙)을 읽는다. 원본은 `인수인계\작성규칙\회독레슨_작성규칙.md` 와 `인수인계\02_이해하기_쉽게_만드는_원칙.md` D, E, F 절이다.

사용자 요청 요지: 강의를 버튼을 눌러 가며 게임하듯, 동영상 보는 기분으로 공부하고 싶다. 한 번에 기출까지 쏟아지면 안 읽힌다. **여러 번 회독**하게 나눠 달라. 1회독은 진짜 쉬운 버전으로 큰 틀, 갈수록 조금씩 더 깊게. 전문용어는 계속 반복 노출해서 저절로 외워지게. (IoT 스마트홈을 보고: "용어가 장난 없다, 읽어도 읽어도 안 익숙해질 것 같다")

사이트는 원래 강의 슬라이드 순서대로 진행한다. 슬라이드마다 먼저 **원본 슬라이드 그림**을 보여 주고(사이트가 자동으로 넣음), 그 뒤에 선택한 회독의 장면들을 누를 때마다 하나씩 보여 준다. "쌓아서 보기" 를 켜면 N회독 때 1~N 회독 장면을 모두 차례로 보여 준다. 그래서 **각 회독은 앞 회독 내용을 반복하지 말고 그다음 층을 더한다.** (반복은 용어와 핵심 한 줄로만)

사이트가 **자동으로** 만드는 것(작성자가 만들지 않음):
- **0회독 "용어 먼저"**: 슬라이드마다 그 쪽 `terms` 에 적은 용어를 카드로 보여 주고 누르면 `say`, `more` 가 나온다. 그래서 **`terms` 에 그 쪽에서 쓰는 용어를 빠짐없이** 적는다(적지 않으면 0회독에 안 나온다).
- 용어 강조와 누르면 뜻, 단원 시작 복습 카드, 용어 카드(간격 반복: 알면 1, 2, 4, 7, 15일 뒤 다시), 용어 퀴즈.

## 1. 파일

- 출력: `work\<과목>\lesson\<덱>_<시작3자리>-<끝3자리>.json` (강의안과 같은 범위).
- 생성 스크립트: 같은 폴더 `build_<덱>_<시작>-<끝>.py`. `json.dump(..., ensure_ascii=False, indent=1)`. 수식이 있으면 raw string.
- 임시 파일은 `<덱>_<범위>_` 로 시작하는 고유 이름.
- 검사: `python tools\checkers\lesson_check.py <json> <시작> <끝>` 이 "통과" 할 때까지.

```json
{"deck": "I3", "from": 1, "to": 16,
 "glossary": [{"ko": "허브", "en": "Hub", "say": "집 안 기기들을 한데 모아 주는 반장 같은 장치",
               "more": "여러 무선 기기의 신호를 받아 인터넷 쪽으로 이어 주고, 인터넷이 끊겨도 집 안 자동화를 돌려요."}],
 "slides": [
  {"p": 4, "title": "허브 기반과 논허브 방식", "terms": ["Hub", "논허브 방식", "Wi-Fi"],
   "pass1": [장면...], "pass2": [장면...], "pass3": [장면...], "pass4": [장면...], "pass5": [장면...]}
 ]}
```
- 맡은 범위의 모든 쪽(p)이 있어야 한다. `pass1` 은 모든 쪽에 최소 1장면(표지, 목차, 빈 슬라이드는 `say` 한 장이면 충분). 나머지 회독은 해당 내용이 없으면 빈 배열.
- `glossary`: 이 범위에서 나오는 전문용어 전부(과목 용어 사전 표기 그대로). `say` 는 아주 쉬운 한 문장, `more` 는 조금 더 들어간 한두 문장(용어 사전의 more, def 참고).
- `terms`: 그 쪽에서 쓰는 용어의 en(없으면 ko) 목록. glossary 에 있는 표기와 같게.

## 2. 자료

| 무엇 | 위치 |
|---|---|
| 자세한 강의안 (주 자료: 설명, 비유, 숫자, 그림, 배경 지식, 시험 포인트, 주의) | `work\<과목>\lecture\<덱>_*.md` |
| 원본 슬라이드 그림 | `work\<과목>\_src\png\<덱>\pNNN.png` (look 장면 좌표를 잡을 때 반드시 본다) |
| 기출, 실기 자료, 용어 사전 | 과목정보.md 표 |

## 3. 회독 단계는 과목정보 5절을 따른다

과목마다 회독 수가 다르다. 과목정보 5절의 표에 적힌 회독만 만든다(예: IoT 스마트홈은 5회독, 친환경건축은 3회독). 공통 원칙:

- 앞 회독은 **쉽고 짧게**, 뒤로 갈수록 한 층씩 깊게. 한 회독에 한 가지 층만 더한다.
- **기출은 기출 회독 전에는 넣지 않는다.** 이해 먼저, 시험은 나중.
- 모든 회독에서 용어는 매번 `**한국어(English)**` 로 불러서, 같은 용어를 회독마다 다시 만난다.

### 회독 층 사전 (과목정보 표의 이름과 짝)

| 층 이름 | 넣는 것 | 넣지 않는 것 | 슬라이드당 |
|---|---|---|---|
| 큰 그림 | 이 슬라이드가 무슨 이야기인지 한 가지. 초등학생에게 말하듯 아주 쉬운 말, 비유, 아주 단순한 그림. 용어는 정식 이름으로 부르되 뜻은 비유로 | 숫자, 표 내용, 계산, 기출, 실기, 예외, 주의 | 1~3장면 |
| 흐름과 뜻 | 이 쪽 용어 **하나하나의 뜻**을 중학생 말로 풀기(`points`, `analogy`, `compare` 로 비슷한 용어 구별), 무엇이 무엇으로 이어지는지 순서(`steps`, 단순 `figure`), 쉬운 `check` 1개(용어 뜻) | 세부 숫자, 규격, 기출, 실기 | 2~5장면 |
| 자세히 | 슬라이드 짚어 읽기(`look`), 표와 목록의 숫자, 규격, 표준 이름 빠짐없이(`points`, `compare`), 새 그림(`figure`), 손계산(`steps`), 교수님 말(`prof`, 녹음 있을 때만), 배경 지식(`bg`) | 기출, 실기 | 3~8장면 |
| 기출 | 실제 기출 문제(`exam`: 원문 요지, 쉬운 풀이, 풀이 단계, 답), 확인 퀴즈(`check`), 외워 쓸 답안 문장(`english`), 헷갈리는 점(`warn`) | 실기 | 관련 있는 쪽만(없으면 빈 배열). 기출이 없는 쪽이라도 시험에 나올 만한 사실은 check 로 |
| 실기 연결 | 과목정보에 정한 실기 자료(과업 번호, 준비물, 순서, 확인 항목, 흔한 실수)를 슬라이드 개념과 짝지어(`steps`, `compare`, `points`, `check`, `warn`). 출처(자료 이름, 과업 번호) 필수 | 자료에 없는 절차 | 관련 있는 쪽만 |

과목정보에 "큰 그림, 자세히, 기출" 세 단계만 있으면 "흐름과 뜻" 의 용어 풀이 장면은 "자세히" 앞부분에 넣는다.

## 4. 장면 종류

`정리슬라이드_작성규칙.md` 의 종류(title, goal, points, analogy, formula, steps, figure, compare, english, check, warn, recap)를 모두 쓸 수 있고, 아래를 더 쓴다.

| kind | 필드 | 화면 |
|---|---|---|
| `say` | `lines` (1~4줄, 줄마다 70자 이내) | 자막처럼 한 줄씩 |
| `look` | `head`, `boxes` ([{"x":0~1, "y":0~1, "w":0~1, "h":0~1, "say":"설명"}] 1~6개) | 슬라이드 그림 위에 박스가 하나씩 켜지고 아래에 설명. 좌표는 그림 왼쪽 위 기준 비율 |
| `bg` | `src` ("기초 다지기 4단원"), `lines` (1~4줄) | 배경 지식 카드 |
| `prof` | `when` ("3주차 화요일 수업"), `lines` (1~4줄) | 교수님 말 카드 |
| `exam` | `src`, `q` (원문 요지), `qko` (쉽게 풀어 한 줄), `solve` (단계 2~6개), `answer` | 문제, 뜻, 풀이 단계, 답 순서로 |

`english` 는 이 과목들에서 "시험 답안에 쓸 문장" 으로 쓴다: `en` 에 외워 쓸 한국어 답안 문장, `ko` 에 핵심 풀이, `tip` 에 외우는 요령.

## 5. 문체와 용어

- 존댓말 "~요". 한 줄 짧게(70자 이내). 한 장면에 너무 많이 넣지 않는다.
- 용어는 나올 때마다 매번 `**한국어(English)**` 형식. 사이트가 용어를 강조하고 누르면 뜻을 띄운다.
- `glossary` 의 각 용어는 파일 전체 글에서 3번 이상 나오게.
- 금지 문자, 이모지 금지. 강의안과 제공 자료에 없는 사실을 지어내지 않는다.
