# 문제은행 작성 규칙

먼저 `00_공통_원칙.md` 와 `work\<과목>\rules\과목정보.md` (특히 시험 모양, 기출 자료)를 읽는다.

기출은 시험마다 모양이 달라서, 한 유형에 치우치지 않고 **객관식, O/X, 단답, 서술, 계산을 고르게** 낸다. 같은 사실을 유형만 바꿔 2~3번 물어도 된다. 사용자가 준 기출은 원문 그대로 넣고 `src` 로 표시한다.

## 1. 출력

- 파일: `work\<과목>\bank\w<주차>_<basic|hard>.json` (JSON 배열). 기출 원문은 `w<주차>_exam.json`, 예상문제는 `w<주차>_expected.json`.
- 반드시 Python 생성 스크립트 `work\<과목>\bank\build_w<주차>_<종류>.py` 로 만든다. 계산 문항 정답은 스크립트 안에서 실제로 계산해서 assert.
- 검사: `python tools\checkers\bank_check.py <json>` 이 "통과" 할 때까지.

## 2. 난이도

| | basic | hard |
|---|---|---|
| 기준 | 슬라이드 내용을 그대로 확인하는 시험 난이도 | 한 단계 위: 개념 두세 개를 엮기, 비슷한 것 구별, 사례에 적용, "왜" 를 묻는 서술 |
| 최소 분량 (주차마다) | mcq 30, ox 20, short 15, essay 6 | mcq 15, ox 10, short 8, essay 5 |

숫자 계산이 나오는 주차는 calc 를 basic 3개 이상, hard 3개 이상 더한다. 모든 단원(unit)에 고르게.

## 3. 공통 필드

| 필드 | 뜻 |
|---|---|
| `id` | 고유 문자열 `w3b-mcq-001` (주차, b/h/x/e, 유형, 번호) |
| `type` | `mcq`, `ox`, `short`, `essay`, `calc` |
| `part` | 주차 문자열 `"1"`, `"3"`. 기출 주차는 과목정보의 기출 주차 id |
| `level` | `"basic"` 또는 `"hard"` |
| `unit` | 단원 이름 `"3-2 주파수와 Zigbee"`. 한 주차 안에서 5~9개를 정해 철자까지 똑같이 |
| `slides` | 근거 슬라이드 `"I3 p.14-15"` |
| `src` | 선택. `"기출 2026 제3회 필기 18번"` (원문 그대로 넣은 기출), `"예상"` (기출 범위 예상문제). 사이트는 첫 단어(기출, 예상)로 모아 푼다 |

텍스트: 굵게 `**...**`, 줄바꿈 `\n`, 필요하면 `$...$`. 금지 문자 em dash, en dash, 가운뎃점.

## 4. 유형별 필드

### mcq (객관식)
`q`, `c`(보기 4개), `a`(정답 인덱스 0~3), `e`(왜 정답이고 헷갈리는 보기는 왜 틀렸는지). 오답 보기는 같은 범주의 그럴듯한 것. "모두 정답" 금지. 문장은 "~으로 가장 적절한 것은?", "~이 아닌 것은?", "옳지 않은 것은?". 기출 원문이 5지선다면 원문 보기 5개를 4개로 줄이지 말고, 정답과 가장 헷갈리는 오답 3개를 남기고 `e` 에 "원문은 5지선다" 라고 적는다.

### ox
`q`(진술), `a`(true/false), `e`(근거). 절반은 false. false 는 헷갈리는 요소 하나만 바꾼다.

### short (단답)
`q`, `a`(허용 답 배열: 정식 표기, 한국어, 영어, 줄임말, 띄어쓰기 변형), `e`. 숫자 답이면 `"num": true, "tol": 0.01` 과 `a` 첫 원소를 숫자 문자열로. 나열형("~ 중 두 가지를 쓰시오")은 short 가 아니라 essay 로.

### essay (서술, 나열형 포함)
| 필드 | 뜻 |
|---|---|
| `q` | 시험 문장 모양: "~에 대해 설명하시오", "~와 ~의 차이를 서술하시오", "~을 세 가지 쓰시오" |
| `answer` | 모범답안 3~7문장(나열형은 항목 목록 문장). 시험장에서 외워 쓸 수 있게 짧고 정확하게 |
| `points` | 채점 항목 4~10개. 짧은 핵심 구절 |
| `model` | 선택. 핵심 개념 이름 |

### calc (계산)
| 필드 | 뜻 |
|---|---|
| `q` | 문제 (필요한 공식과 값을 문제 안에 준다) |
| `qko` | 선택. 무엇을 구하는지 쉽게 한 줄 + 반올림 규칙 |
| `blanks` | 채점 칸 `[{"label": "환기횟수(회/h)", "ans": 2, "tol": 0.01}]` 1~6칸 |
| `steps` | 풀이 단계 3~8개 (식 먼저, 그다음 숫자 대입) |
| `answer` | 최종 답 한눈에 |
| `e` | 흔한 실수 |

## 5. 기출 다룰 때

- 원문을 바꾸지 않는다(금지 문자와 공백만 정리). `src` 에 시험 이름과 번호.
- 해설이 없는 기출은 자료(가이드북, 용어해설집, 기준, 강의)로 풀고, 확신이 없으면 `e` 첫머리에 "(풀이 기준 정답, 확인 필요)".
- 기출 해설이나 자료끼리 다르면 `e` 에 차이를 적는다.
- 같은 사실을 다른 각도로 묻는 변형 문항을 basic/hard 에 2~3개씩 만든다(src 없음).
