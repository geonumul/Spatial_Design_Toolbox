# 회독 공부 데이터 형식

어려운 과목(현재 IoT 스마트홈)에 쓰는 "회독 공부" 탭의 데이터 형식이다. 한 강의 내용을 세 번 다른 깊이로 읽게 해서, 정확한 용어가 반복 노출로 자연스럽게 외워지게 한다. 화면은 게임처럼 한 블록씩 눌러 가며 진행하고, 누를 때마다 XP가 쌓인다.

- 1회독 **큰그림**: 초등학생 수준. 비유와 그림 위주. 용어는 정식 표기 그대로 등장시키되 설명은 아주 쉽게.
- 2회독 **조금 자세히**: 중학생 수준. 왜 그런지, 무엇과 무엇이 다른지, 어떤 순서로 동작하는지.
- 3회독 **자세히 + 시험**: 중학생 말투 그대로, 강의의 모든 사실(숫자, 표준 이름, 규격)과 기출 포인트까지.

세 회독 모두 같은 용어를 다시 부른다. 용어 자체는 절대 쉬운 말로 바꾸지 않는다(시험에 정식 용어로 나온다). 쉬운 것은 설명뿐이다.

## 파일

```
content/<slug>/unit<N>.json        단원 하나 = 강의자료 하나
content/<slug>/terms.json          용어 사전 (모든 단원 공용)
content/<slug>/bank_unit<N>.json   문제풀기용 문항 (작업가이드 5-2 형식)
content/<slug>/exam_bank.json      기출 문항 (src "기출")
```

`python tools/build_study.py <slug>`가 이 파일들을 과목 페이지에 넣는다.

## unit<N>.json

```json
{
  "part": "3",
  "title": "무선통신 I: 허브와 근거리 무선(WPAN)",
  "source": "3강 마스터 교안",
  "lessons": [
    {
      "id": "u3l1",
      "title": "지능형홈의 심장, 허브",
      "emoji": "🧠",
      "terms": ["허브", "논허브 방식"],
      "r1": [ 블록, ... ],
      "r2": [ 블록, ... ],
      "r3": [ 블록, ... ]
    }
  ]
}
```

- `id`: `u<단원>l<순번>`. 한 번 정하면 바꾸지 않는다(진행 기록 연결).
- `lessons`: 한 단원에 3~8개. 한 레슨은 5~10분 분량.
- `terms`: 이 레슨에서 처음 또는 중요하게 다루는 용어 키(`terms.json`의 `key`).

## terms.json

```json
[
  {"key":"허브","term":"허브(Hub)","en":"Hub","unit":"3",
   "r1":"집 안 IoT 기기들을 한데 모아 주는 반장",
   "r2":"여러 무선 기기의 신호를 받아 인터넷 쪽으로 이어 주고, 인터넷이 끊겨도 집 안에서 자동화를 돌리는 로컬 장치",
   "r3":"(강의 정의 그대로) + 시험에서 헷갈리는 포인트",
   "exam":true}
]
```

- `key`: 본문에서 `[[허브]]`로 부르는 이름. 과목 전체에서 유일.
- `term`: 화면에 크게 보이는 정식 표기(영문 병기).
- `r1`/`r2`/`r3`: 회독 수준별 설명. r1은 한 문장, r2는 한두 문장, r3은 정확한 정의.
- `exam`: 기출에 나왔거나 나올 가능성이 큰 용어면 true (도감에 "기출" 표시).

## 블록

본문 문자열(`h`, `q`, `a`, `e`, `k`, `v`, `f`, `b`)에는 HTML을 쓰지 않는다. 대신 다음 표시만 쓴다.

- `[[용어키]]`: 누르면 용어 카드가 뜨는 용어 칩. 조사는 괄호 밖에: `[[허브]]는`.
- `**굵게**`: 강조.

| t | 모양 | 필드 |
|---|---|---|
| `say` | 말풍선 문단 | `h` |
| `big` | 크게 보이는 핵심 한 줄 | `h` |
| `story` | 라벨과 설명 목록 | `items:[{k,v}]` |
| `reveal` | 질문 누르면 답 공개 | `q`, `a` |
| `blank` | 빈칸 누르면 채워짐 | `h` 안에 `{{정답}}` 여러 개 |
| `cards` | 뒤집는 카드 | `items:[{f,b}]` (2~6장) |
| `table` | 비교표. `hide:true`면 칸을 눌러야 보임 | `cols:[]`, `rows:[[]]`, `hide` |
| `steps` | 한 단계씩 눌러 펼치는 순서 | `title`, `items:[{k,v}]` |
| `order` | 섞인 항목을 순서대로 누르기 | `q`, `items:[]` (정답 순서, 3~6개) |
| `match` | 왼쪽과 오른쪽 짝 맞추기 | `q`, `pairs:[[왼,오],...]` (3~5쌍) |
| `pick` | 4지 선택 | `q`, `c:[4개]`, `a`(0부터), `e` |
| `ox` | O/X | `q`, `a`(true/false), `e` |
| `chart` | 숫자 막대 비교 | `title`, `unit`, `bars:[{k,v}]` |
| `svg` | 그림. `data-spot` 붙은 요소를 누르면 설명 | `svg`, `cap`, `spots:{id:{k,v}}` |
| `exam` | 기출 포인트 상자 | `h`, `ref`(예: "2026 제3회 필기 12번") |
| `img` | 슬라이드 그림 (빌드 때 base64로 들어감) | `file`(단원 폴더 기준 경로, JPEG 가로 900px 이하), `cap` |
| `tip` | 외우는 법, 말장난 | `h` |

### svg 규칙

- 유일하게 마크업을 직접 쓰는 블록. `<svg viewBox="0 0 640 H">`로 시작, 가로 640 기준, 글자 크기 14 이상.
- 색은 클래스로만: 채움 `c1`(연보라) `c2`(연파랑) `c3`(연초록) `c4`(연주황) `c5`(연분홍) `c6`(회색), 선 `ln`, 강조선 `ln2`, 글자 `tx`, 작은 글자 `tx2`. `fill`, `stroke` 색을 직접 쓰지 않는다.
- 누를 수 있는 요소에는 `data-spot="id"`를 붙이고 `spots`에 설명을 둔다. 3~8개.
- `<script>`, 외부 이미지, `on*` 속성 금지.

### 회독별 분량

| | 블록 수 | 상호작용 블록(reveal, blank, cards, table hide, steps, order, match, pick, ox, svg spots) |
|---|---|---|
| r1 | 6~12 | 2개 이상 |
| r2 | 10~18 | 4개 이상 |
| r3 | 14~25 | 6개 이상, `exam` 블록은 관련 기출이 있으면 반드시 |

### 문장부호

가운뎃점(·), em dash(—), en dash(–) 금지. 쉼표, 마침표, 슬래시, 화살표(→), 괄호로 대체.
