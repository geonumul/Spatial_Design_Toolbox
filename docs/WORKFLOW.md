## 2. 강의자료 (매주)

- 강의자료 1개 = 1단원. `h1.part`는 `N단원. 제목`, PARTS는 `{"id":"N","name":"N단원 제목","short":"N단원","scope":"중간" 또는 "기말"}`.
- 섹션 id는 그 과목의 마지막 섹션 번호 다음부터. h2와 문항 unit은 `N-M. 제목` / `N-M 키워드`.
- 목차 버튼만 추가하면 단원별 접기는 자동이다.
- 작업가이드 10절 절차대로 넣고 11절 검증, 끝나면 `python tools/sync_home.py`.
- 중간/기말 범위가 정해지면 PARTS의 `scope`만 고친다.

### 회독 공부 과목 (현재 IoT 스마트홈)

어려운 과목은 정리노트 대신 "회독 공부" 탭(1회독 큰그림 초등학생 수준, 2회독 중학생 조금 자세히, 3회독 중학생 말투로 자세히 + 기출)과 "용어 도감" 탭을 쓴다. 이 과목은 HTML을 직접 고치지 않고 JSON을 추가한 뒤 빌드한다.

1. 강의자료 1개 → `content/<slug>/unit<N>.json`, 용어 `terms_unit<N>.json`, 문항 `bank_unit<N>.json` (형식: `docs/STUDY_FORMAT.md`). 그림은 `content/<slug>/img/`.
2. 용어 key는 기존 `terms*.json`에 있는 이름을 그대로 재사용한다(같은 용어가 도감에 두 번 생기지 않게).
3. `python tools/build_study.py <slug>` → "확인 필요" 목록이 비어야 한다.
4. 레슨 id(`u3l2` 등)는 한 번 정하면 바꾸지 않는다(회독 완료 기록 연결).

## 3. 기출문제

1. 기출 문항은 원문 그대로 문제은행에 넣고 `"src":"기출"`을 붙인다. 유형은 원래 형식에 맞춘다(선택형 → mcq, 단답 → short, 나열형과 서술형 → essay의 points, 계산 → short에 숫자 답과 풀이를 e에).
2. 같은 사실을 다른 각도로 묻는 변형 문항을 2~3개씩 추가한다(src 없음).
3. 출제 경향(자주 나온 단원, 형식, 배점)을 그 과목 암기 팁에 "기출 경향" 카드로 정리한다.
4. 기출에만 있고 강의자료에 없는 내용은 해당 단원 노트에 `.said` 대신 `.term` 박스로 "기출에서 확인된 내용"이라고 밝혀 적는다.
5. 사용자는 문제풀기 모드 **기출, 강조 문제**로 모아 풀 수 있다.

## 4. 수업 녹음

1. 녹음을 텍스트로 옮긴다. Claude는 오디오를 직접 들을 수 없으므로 로컬에서 음성 인식을 돌린다: `pip install faster-whisper` 후 `large-v3` 또는 `medium` 모델, `language="ko"`. 결과 텍스트를 `녹음\` 폴더에 같은 이름 `.txt`로 저장.
2. 텍스트를 해당 주차 강의자료와 대조해서 다음을 찾는다.
   - 교수가 반복하거나 "시험에 나온다", "중요하다", "꼭 외워라"라고 한 내용
   - 슬라이드에 없는데 말로 덧붙인 설명, 예시, 숫자
3. 노트: 해당 섹션의 `.orig` 뒤에 `<div class="said">내용</div>`를 넣는다(원문 `.orig`는 건드리지 않음). 화면에 "수업 중 강조" 라벨이 붙는다.
4. 문제: 강조 내용으로 문항을 만들고 `"src":"강조"`를 붙인다. 이미 있는 문항이 강조 대상이면 그 문항에 `src`만 추가한다(id, q는 그대로).
5. 음성 인식 오류가 의심되는 인명, 숫자는 강의자료 표기를 따르고, 확인이 안 되면 넣지 않는다.
