내 펫을 노트북 화면 위에 띄워요

내 펫이 브라우저 밖으로 나와 화면 아래, 작업 표시줄 위, 열어 둔 창 위를 걸어 다녀요. 카카오톡처럼 아이콘으로 켜는 TSG 펫 창에서 친구와 채팅하고, 펫에게 밥과 물도 줘요.

설치 파일 받기 버전 1.4.6, 윈도우 10, 11 용 (약 90MB). 관리자 권한 없이 내 계정에만 설치돼요.
1.4.6: 내 펫을 휙 던지면 날아가고, 친구 화면의 내 펫도 같이 날아가요. 친구 화면에는 몇 초에서 30초쯤 늦게 보이고, 화면 크기가 서로 달라서 자리는 화면 안의 비슷한 곳(비율)으로 맞춰요.
1.4.5: 업데이트할 때 "spawn EBUSY" 오류 창과 함께 꺼지던 문제를 고쳤어요. 예전 버전에서 올라오거나 새 컴퓨터에서 켤 때 오류 창이 뜨던 문제도 줄였어요. 그래도 오류 창이 뜨면 "기록 파일 열기" 로 error.log 를 보내 주세요.
1.4.4 에서 달라진 점. 업데이트 설치가 멈추던 문제를 고쳤고, 새 버전은 일하는 중에 창을 띄우지 않고 조용히 받아 둬요. 펫이랑 채팅 같이, 채팅만, 펫만을 채팅 버튼 옆이나 트레이에서 한 번에 바꿔요. 콕 찌를 때 버벅이던 것도 줄였어요.
1.4.2, 1.4.3 에서 달라진 점. 1.4.3 은 펫과 채팅 버튼이 안 눌리던 문제, 업데이트가 멈추던 문제, 작업 표시줄 경계 문제를 고쳤어요. 내 펫이 장기를 하거나 새로 배우면 친구 화면의 내 펫도 같은 장기를 보여 줘요. 친구가 콕 찌르면 친구 펫이 걸어와서 콕 찌르고 내 펫이 깜짝 놀라요. 오른쪽 아래 알림 창도 떠요 (꺼져 있던 동안 온 것도 켜면 보여요). 친구 펫이 밥을 먹거나 개인기를 하면 내 화면에서도 같이 보여요. 펫만 숨기고 오른쪽 채팅 버튼은 남길 수 있고, 채팅 창을 고정하거나 너비를 바꿀 수 있어요. 관리자가 보낸 코인도 받아요.
업데이트가 멈추거나 안 되면 여기서 직접 받아 설치해 주세요. 위 설치 파일 받기 로 받아 실행하면 펫과 설정은 그대로 두고 새 버전으로 바뀌어요. 1.4.2 이하는 받는 게이지가 중간에 멈춘 채로 있을 수 있어요. 1.4.3 부터는 멈추면 이어 받고, 안 되면 이유와 직접 받기 버튼을 보여 줘요.
업데이트하다가 "A JavaScript error occurred" (spawn EBUSY) 창이 떴거나 "설치를 시작했어요" 에서 멈춰 있으면 화면 오른쪽 아래 트레이의 TSG 펫 아이콘을 오른쪽 클릭해 끝내기 를 누르고(안 꺼지면 작업 관리자에서 TSG 펫을 끝내기), 위 버튼으로 받아 설치해 주세요. 1.4.4 부터는 이렇게 멈추지 않아요.
1.3.2 부터는 스스로 업데이트해요. 새 버전이 나오면 펫 프로그램이 작은 창으로 알려 주고, 지금 업데이트 를 누르면 받아서 설치한 뒤 다시 켜져요. 트레이 메뉴의 업데이트 확인 으로 직접 볼 수도 있어요. 그 전 버전(1.3.1 이하)을 쓰고 있다면 이 기능이 없으니 위 버튼으로 한 번만 다시 설치해 주세요. 설정과 펫은 그대로예요.
파란 경고 창이 떠도 괜찮아요. 이 프로그램은 코드 서명을 하지 않아서 처음 실행할 때 윈도우가 "Windows의 PC 보호" 창을 보여 줄 수 있어요. 그럴 때는 추가 정보 를 누르고 실행 을 누르면 설치가 계속돼요.

설치하고 처음 켜면

  1. 받은 TSG-Pet-Setup.exe 를 실행하면 설치 마법사가 나와요. 다음, 이용약관 동의함, 설치 폴더, 설치 선택(바탕화면 바로가기, 시작 메뉴, 컴퓨터 켤 때 자동 실행)을 고르고 설치 를 눌러요.
  2. 마지막 화면에서 TSG 펫 실행 이 체크된 채로 마침 을 누르면 TSG 펫 창이 열리고 펫이 화면에 나타나요. 다음부터는 바탕화면이나 시작 메뉴의 TSG 펫 아이콘으로 켜요.
  3. 구글 계정으로 로그인 을 누르면 브라우저가 열려요. 로그인하고 "TSG 펫을 열까요?" 에서 열기를 누르면 프로그램으로 돌아와요.
  4. 동물을 고르고 이름을 지어 데려오기 를 눌러요. 이름은 다른 친구와 겹치면 안 돼요. 사이트에서 이미 데려온 펫이 있으면 그 펫이 그대로 나와요.
  5. 나중에 내 펫 탭에서 이름이나 동물을 바꿀 수 있어요. 동물을 바꾸면 친해진 정도는 다시 아기부터지만, 간식 돈과 옷장, 배운 장기는 그대로예요.
  6. 펫과 헤어지고 싶으면 내 펫 탭 아래나 내 펫 페이지의 펫 떠나보내기 를 눌러요. 두 번 확인한 뒤 펫, 펫 이름, 간식 돈, 개인기, 옷장, 친구 목록이 모두 지워지고 되돌릴 수 없어요.
  7. TSG 펫 창의 X 를 눌러도 꺼지지 않고 오른쪽 아래 트레이에 남아요 (카카오톡처럼). 트레이의 고양이 아이콘을 누르면 다시 열리고, 완전히 끄려면 설정 이나 트레이 메뉴의 끝내기 를 눌러요.
  8. 내 펫 페이지 맨 위 노트북 화면에 띄우기 버튼으로도 펫을 켜고 끌 수 있어요.

TSG 펫 창

친구펫 이름으로 친구 추가, 받은 요청, 친구마다 키우는 사람과 산책 중 표시
채팅전체 채팅방과 친구마다 1:1 방, 안 읽은 수
내 펫밥, 물, 씻기기, 재우기, 장기, 옷장, 이름과 동물 바꾸기
설정펫 띄우기, 자동 실행, 알림, 방해 금지 시간, 업데이트, 로그아웃

펫이 졸라요

  • 시간이 지나면 배고프고, 목마르고, 심심하고, 꼬질꼬질해지고, 밤에는 졸려요. 그러면 펫 위에 말풍선이 떠서 "배고파요, 밥 주세요", "목말라요, 물 주세요" 하고 졸라요.
  • 말풍선의 버튼으로 바로 밥 주기(사료 12, 간식 25), 물 주기(공짜), 씻기기(공짜), 재우기, 쓰다듬기를 할 수 있어요. 사이트 내 펫 페이지에서 돌봐도 같이 반영돼요.
  • 같은 말은 25분에 한 번만 하고, 방해 금지 시간(기본 밤 11시부터 아침 8시)과 전체 화면으로 영상을 볼 때는 조르지 않아요. 윈도우 알림은 설정에서 켜야 와요.
  • 오래 못 돌봐도 펫이나 간식 돈은 사라지지 않아요. 배고프고 목마르면 슬픈 얼굴로 느릿느릿 걷고 장기를 안 할 뿐이에요.

펫이랑 놀기

더블클릭그 자리에 앉아서 기다려요

오른쪽 클릭채팅 열기, 친구 목록, 개인기 보여 줘, 내 펫, 숨기기, 끝내기

개인기

  • 내 펫 페이지의 장기 탭에서 배운 개인기(앉아, 손, 빙글빙글, 윙크 애교, 점프, 데굴데굴, 엉덩이 춤)를 화면 위 펫도 해요.
  • 내 펫을 오른쪽 클릭하고 개인기 보여 줘 에서 골라요. 배운 것만 나와요. 가만히 두면 가끔(10~20분마다) 혼자서도 보여 줘요.
  • 친구 펫을 누르고 개인기 보기 를 누르면 그 친구가 배운 개인기를 내 화면에서 보여 줘요.

채팅하는 법

  1. 화면 오른쪽 끝에 붙은 분홍 채팅 버튼을 누르면 채팅 창이 옆에서 나오고, 한 번 더 누르거나 Esc 를 누르면 쏙 들어가요. 버튼은 위아래로 끌어 옮길 수 있고, 안 읽은 메시지 수가 붙어요.
  2. 채팅 창 위에 탭이 세 개 있어요. 전체는 내 친구 모두에게 한 번에, 1:1은 친구 한 명과 둘이서, 내 펫은 로그인과 펫 고르기예요. 탭마다 안 읽은 수가 따로 나와요.
  3. 친구 추가는 1:1 탭에서 해요. 내 펫 이름을 친구에게 알려 주고, 친구의 펫 이름을 칸에 넣어 친구 요청을 눌러요. 내 펫 페이지의 친구 칸에서도 똑같이 돼요.
  4. 요청을 받은 친구가 수락을 누르면 친구가 돼요. 둘 다 동의해야 해서, 이름만 안다고 마음대로 친구가 되지는 않아요.
  5. 친구 목록과 대화에는 펫 이름 옆에 키우는 사람 이름이 작게 나와서 누구 펫인지 알 수 있어요. 친구에게 보이는 내 이름은 내 펫 탭이나 내 펫 페이지 친구 칸에서 바꿀 수 있어요 (서로 친구에게만 보여요).
  6. 한마디 쓰고 Enter 를 누르면 친구 화면에서 내 펫 위에 말풍선으로 떠요. 1:1 은 그 친구에게만, 전체는 친구 모두에게 보여요.
  7. 키보드로는 Ctrl + Shift + Space 로 언제든 열고 닫을 수 있어요.

채팅은 로그인하고 서로 친구 추가한 사람끼리만 돼요. 친구가 아닌 사람은 내 글을 볼 수 없어요. 친구를 끊으려면 1:1 대화 창 위쪽 사람 모양 버튼이나 내 펫 페이지에서 끊기를 눌러요.

친구들도 같이 나와요

  • 서로 친구 추가한 사람의 펫만 같이 나와요. 5분 안에 사이트나 펫 프로그램을 쓴 친구 펫은 걸어 다니고, 나머지는 왼쪽 아래에서 새근새근 자요.
  • 콕 찌르기: 화면에 나온 친구 펫을 누르고 콕 찌르기를 누르면 내 펫이 걸어가서 콕 찌르고, 친구 컴퓨터에 알림이 가요. 친구마다 30초에 한 번 찌를 수 있고, 알림은 트레이 메뉴에서 끌 수 있어요.
  • 로그인하지 않으면 내 펫만 나오고 인터넷은 전혀 쓰지 않아요.

지우고 싶을 때

윈도우 설정, 앱, 설치된 앱에서 TSG 펫 을 찾아 제거하면 돼요.
