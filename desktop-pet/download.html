과목 사용법 이용권 내 펫

내 펫을 노트북 화면 위에 띄워요

사이트에서 키우는 펫이 브라우저 밖으로 나와 화면 아래, 작업 표시줄 위, 열어 둔 창 위를 걸어 다녀요. 공부하는 동안 옆에 두는 작은 친구예요.

설치 파일 받기 윈도우 10, 11 용 (약 95MB). 관리자 권한 없이 내 계정에만 설치돼요.
9월 17일에 새 버전이 나왔어요. 이제 친구 추가한 사람끼리만 펫이 보이고 1:1로 채팅해요. 예전 버전으로는 채팅이 안 되니 이미 설치했어도 위 버튼으로 다시 받아 설치해 주세요. 같이 쓰는 친구들도 모두 새 버전이어야 해요.
파란 경고 창이 떠도 괜찮아요. 이 프로그램은 코드 서명을 하지 않아서 처음 실행할 때 윈도우가 "Windows의 PC 보호" 창을 보여 줄 수 있어요. 그럴 때는 추가 정보 를 누르고 실행 을 누르면 설치가 계속돼요.

쓰는 법

  1. 받은 TSG-Pet-Setup.exe 를 실행해서 설치해요. 설치가 끝나면 펫이 한 번 나타나요.
  2. 사이트에서 내 펫 화면에 띄우기 버튼을 누르면 펫이 나타나고, 한 번 더 누르면 숨어요.
  3. 브라우저가 "TSG 펫을 열까요?" 하고 물으면 열기를 눌러 주세요. 항상 허용에 체크하면 다음부터는 안 물어봐요.
  4. 화면 오른쪽 아래 트레이의 고양이 아이콘에서도 보이기, 숨기기, 끝내기를 할 수 있어요.

펫이랑 놀기

클릭하트가 뿅, 콩 뛰거나 빙글 돌아요
더블클릭그 자리에 앉아서 기다려요
끌어서 놓기살포시 떨어져서 다시 걸어요
오른쪽 클릭채팅 열기, 친구 목록, 숨기기, 끝내기

채팅하는 법

  1. 먼저 친구를 추가해요. 내 펫 페이지의 친구 칸이나 펫 채팅 창에 내 친구 코드(예: ACD-479)가 있어요. 이 코드를 친구에게 알려 주고, 친구 코드는 칸에 넣어 친구 요청을 눌러요.
  2. 요청을 받은 친구가 수락을 누르면 친구가 돼요. 둘 다 동의해야 해서, 코드만 안다고 마음대로 친구가 되지는 않아요.
  3. 화면 오른쪽 끝에 붙은 분홍 채팅 버튼을 누르면 채팅 창이 옆에서 나오고, 한 번 더 누르면 쏙 들어가요. 버튼은 위아래로 끌어 옮길 수 있고 트레이 메뉴에서 숨길 수 있어요.
  4. 내 펫에 마우스를 올리면 머리 위에 동그란 버튼 두 개가 떠요. 분홍 말풍선 버튼을 누르면 펫 옆에 채팅 창이 열리고 친구 목록이 나와요. 이야기할 친구를 눌러요.
  5. 아래 칸에 한마디 쓰고 Enter 를 누르면 그 친구 화면에서 내 펫 위에 말풍선으로 떠요. 다른 친구에게는 안 보여요. 닫을 때는 Esc 나 X 를 눌러요.
  6. 키보드로는 Ctrl + Shift + Space 로 언제든 열고 닫을 수 있어요. 옆의 친구 버튼을 누르면 친구 목록이 나오고, 친구를 고르면 내 펫이 놀러 가요.

채팅은 사이트에 로그인하고 서로 친구 추가한 사람끼리만 돼요. 창을 닫아 둔 사이 새 메시지가 오면 내 펫에 분홍 숫자가 붙고, 채팅 창 친구 목록에 친구마다 안 읽은 개수가 나와요. 친구를 끊으려면 대화 창 위쪽 사람 모양 버튼이나 내 펫 페이지에서 끊기를 눌러요.

친구들도 같이 나와요

  • 사이트에 로그인한 상태로 버튼을 누르면 서로 친구 추가한 사람의 펫만 같이 나와요. 5분 안에 사이트나 펫 프로그램을 쓴 친구 펫은 걸어 다니고, 나머지는 왼쪽 아래에서 새근새근 자요.
  • 콕 찌르기: 화면에 나온 친구 펫을 누르고 콕 찌르기를 누르면 내 펫이 걸어가서 콕 찌르고, 친구 컴퓨터에 알림이 가요. 친구마다 30초에 한 번 찌를 수 있고, 알림은 트레이 메뉴에서 끌 수 있어요.
  • 친구가 아닌 사람은 내 펫이 켜져 있는지도 볼 수 없어요.
  • 로그인하지 않으면 내 펫만 나오고 인터넷은 전혀 쓰지 않아요.

지우고 싶을 때

윈도우 설정, 앱, 설치된 앱에서 TSG 펫 을 찾아 제거하면 돼요.
